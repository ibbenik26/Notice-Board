How to Host Free on GitHub Pages or Netlify

  1. Create Firebase Project: Go to console.firebase.google.com, create a free project, enable Firestore Database in test mode, and copy your web app credentials above.
  2. Host `index.html`: Create a GitHub repository (e.g., `school-noticeboard`), upload this `index.html` file, and enable GitHub Pages in repository settings.
  3. Remote Control Screen: Open the hosted web URL on your TV browser. Then open the same URL on your laptop or phone, enter PIN 1234, and update notice slides live from anywhere!
